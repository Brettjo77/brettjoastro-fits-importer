The problem

“Hang on — did I back that up?”

Smart telescopes fill up fast, and hand-copying folders around leaves you guessing. Delete too early and a night's data is gone; delete too late and the camera is full at 2am under a clear sky. Most import scripts just copy — they can't prove anything arrived intact, and they forget everything the moment you archive a finished target.

The answer

Backup-first, with receipts

1

Plug in, panel opens

A launchd watcher spots either camera mounting, scans read-only, sends a notification, and opens the local control panel. Tick targets, hit import. No terminal needed.

2

Copies you can trust

Each frame is stream-hashed from the camera, written to a .partial, fsynced, re-read from disk and re-hashed before it counts. Nothing is ever marked imported unless the bytes on your Mac provably match the camera.

3

A lifetime ledger

Every frame from every camera joins one register — SHA-256, exposure, night, scope, day number. Archive finished targets wherever you like: the ledger still knows, so nothing re-imports and history survives.

4

Cleanup only when provable

The Seestar's end-of-run delete offer lists only folders in which every single file is ledger-verified. The ASIAir is treated as a backup of record — it never offers deletion at all.

Safety model

Designed around one rule: never lose a frame

  • Crash-safe copies — interrupted transfers leave a .partial, never a half-file posing as a backup; re-running resumes with zero double-copies.
  • The camera is read-only — the ASIAir is never modified beyond optional purple done-tags; nothing on any camera is touched without a verified copy and your explicit Yes.
  • Empty scans never clear anything — a half-mounted drive can't convince the ledger that files vanished.
  • Honest categories — the backup report separates “verified” from “backed up, unverified” from “still on camera only”, and tells you exactly what's safe to clear.
  • Everything is inspectable — the ledger is plain JSON, history is an append-only log, and a published mirror keeps a browsable copy of it all.
Get it

Install in two minutes

Requires macOS with Xcode Command Line Tools Python 3 and astropy. Built and tested on a ZWO ASI585MC Air and a Seestar S30 Pro.

git clone https://github.com/Brettjo77/brettjoastro-fits-importer.git
cd brettjoastro-fits-importer
bash install-scripts.sh
# then plug a camera in — the panel opens by itself

Custom folder locations? Copy config.example.json to ~/Library/Application Support/Astro Import/config.json and edit — the installer never overwrites it. First run on an existing archive? Use --baseline so your history joins the ledger without copying a thing, then --reconcile to verify what's already on disk.
